信徒管理 使用說明

回到 App

給第一次使用的人。照順序做，大約 10 分鐘。

你的資料只屬於你。資料存在你自己的手機；開了同步，才會另外存一份在你自己的加密雲端。網站作者和其他使用者都看不到。

1. 安裝到手機

網址：https://fyj5867.github.io/shinnyo-member-management/

iPhone

  1. 用 Safari 打開上面的網址。從 LINE 裡直接點開的不行，要複製網址到 Safari。
  2. 按下方的「分享」→「加入主畫面」→「加入」。
  3. 之後都從主畫面的圖示打開。生日通知只有這樣才能開。

Android

  1. 用 Chrome 打開網址。
  2. 右上角「⋮」→「加到主畫面」或「安裝應用程式」。

電腦

用 Chrome 或 Edge 打開網址就能用。網址列右邊有「安裝」可以做成桌面圖示。

2. 開始使用

只用一台手機的話，做完這一段就可以用了，不需要同步。

  1. 設定 → 單位名稱：例如「○○苑」，會印在列印的抬頭。
  2. 設定 → 年度金額：填苑費、祈念證、星供、星供套的單價。每一筆之後也可以個別改金額。
  3. 建立名冊，二選一：
    • 一個一個加：名冊 → ＋新增。之後在某一戶按「＋」，選「導子」或「家族入信」，關係會自動建好。
    • 人數多的話，用 Excel 匯入，見下一段。
沒開同步的話，請定期備份。設定 → 備份 → 下載備份 JSON，存到私人的地方。手機壞掉或換手機時，只能靠這個檔救回資料。

3. 匯入 Excel 名冊

  1. 先到 設定 → 匯出 → 下載空白範本，拿到欄位排好的 Excel。
  2. 一個人填一列。姓名填在他那一層的欄位：導親、導子、所屬、家族入信。
  3. 要照順序排：
    • 導子會掛在上面最近的導親下面。
    • 所屬會掛在上面最近的導子下面。
    • 家族入信會掛在上面最近的那一戶。
  4. 苑費欄填 v（要繳）或 x（不繳）。標題寫年度，例如「2027 苑費」。
  5. 日期寫成 1980.01.01。
  6. 已經過世的人，姓名後面加「(歿)」。
  7. 標題對不上內建欄位的，會變成自訂欄位，例如「靈位」。
  8. 你自己的導親：放在最上面的導親欄，下面不放人、苑費留空。App 會當成參考，不列入苑費和統計。

填好後到 設定 → 匯入 Excel 名冊 選檔案。匯入前會先列出人數和要核對的地方，按確定才會寫入。

檔案只在你的裝置上讀取，不會上傳。之後再匯入一次是「對人更新」：信徒編號或姓名對得到的人，星供、實踐、奠供帳都會保留。

4. 跨裝置同步

想讓手機和電腦看到同一份資料才需要。用的是你自己的 GitHub 帳號（免費）。資料在上傳前就加密，只有你的同步密語打得開。

步驟 A：申請 GitHub 帳號

  1. 到 github.com 按「Sign up」，用 email 註冊。已經有帳號就跳過。
  2. GitHub 可能會要你開「兩步驟驗證」，照畫面做就好。

步驟 B：建立金鑰

  1. App 裡 設定 → 跨裝置同步，點「建立 GitHub 金鑰（只勾 gist）」。
  2. 登入 GitHub 後會打開建立金鑰的頁面。名稱「信徒管理同步」和 gist 已經幫你填好、勾好，其他都不要勾。
  3. 「Expiration」（有效期限）選 No expiration。選有期限的話，到期同步就會停，要重建一把。
  4. 拉到最下面按「Generate token」。
  5. 複製 ghp_ 開頭的那一長串。這串只會顯示一次，先不要關掉頁面。

步驟 C：連線

  1. 回到 App，把金鑰貼進「貼上金鑰 ghp_…」。
  2. 自訂一組同步密語，至少 8 個字。
  3. 按「連線並開始同步」。右上角顯示「已同步」就完成了。
同步密語請寫在紙上收好。忘記的話，雲端的資料就打不開，作者也救不回來。

5. 加第二台裝置

例如電腦，或家人幫忙用的另一支手機。不用再建金鑰，用配對碼就好。

  1. 在已經連好的那台：設定 → 跨裝置同步 → 配對碼 →「複製」。
  2. 把配對碼傳給自己，例如 LINE 的 Keep 或寄 email 給自己。不要傳到群組或給別人。
  3. 在新的那台打開 App：設定 → 方法二，貼上配對碼，按「用配對碼連線」。密語可以留空。
  4. 連上後，把剛剛傳的配對碼訊息刪掉。

之後每分鐘、每次切回 App 都會自動同步。

6. 平常要注意

  • 金鑰、同步密語、配對碼，三個都等於你全部資料的鑰匙。不要給別人，也不要截圖分享。
  • 備份 JSON 有完整的個人資料。請存在私人的地方，不要放到公開的雲端資料夾。
  • 生日匯出到行事曆時，請加到私人的行事曆，不要加到公司的 Outlook（會同步到公司伺服器）。
  • GitHub 上有一份「信徒管理 Shinnyo Members 同步資料（請勿刪除）」，那就是你的雲端資料，不要刪。奠供帳的照片也是一張一份「信徒管理 加密照片」。
  • 手機遺失時：
    1. 電腦登入 GitHub → 右上頭像 → Settings → Developer settings → Personal access tokens → Tokens (classic)。
    2. 把「信徒管理同步」那把刪掉，遺失的手機就連不上了。
    3. 照步驟 B 建一把新的，用原本的密語重新連線，資料都還在。

7. 常見問題

會跟別人的資料混在一起嗎？
不會。每個人用自己的 GitHub 和密語，各自一份。
看不到新功能？
把 App 完全關掉再打開。電腦的話重新整理網頁。
右上角顯示「需要同步密語」？
到「設定」輸入你的同步密語。
出現「GitHub 金鑰無效或已過期」？
照步驟 B 建一把新的金鑰，用原本的密語重新連線。
生日提醒怎麼開？
設定 → 生日提醒。iPhone 要從主畫面的圖示打開才能開通知。想要沒開 App 也會提醒，按「匯出全部生日」加到手機行事曆。
奠供帳的照片存在哪？
存在拍照的那台。有開同步的話，會加密傳到你的雲端，其他裝置打開時再下載。備份 JSON 不含照片。
不用了，怎麼刪乾淨？
先下載一份備份 JSON 自己留著。然後 設定 → 跨裝置同步 → 中斷，刪掉主畫面的圖示，並在瀏覽器清除這個網站的資料。最後到 GitHub 刪掉上面那些 Gist 和「信徒管理同步」金鑰。
