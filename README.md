# 信徒管理

信徒名冊（導親・導子・所屬・家族入信）、年度苑費與祈念證、實踐（精進的細項）、星供申請、費用總結、奠供帳。手機優先，版型照原本的 Excel 名冊與星供表。
手機與電腦共用同一份資料（機制同「行動祕書」「安規工具」：加密私密 Gist 同步）。

## 隱私設計
- **這個站台是公開的，程式碼裡沒有任何人名、電話、金額。**
- 資料只存在使用者裝置的 localStorage，與一份 **AES-GCM 加密**的私密 Gist。沒有同步密語就不會上傳。
- 備份 JSON、匯入用的 Excel／PDF／Word 都含個資，**不要放進本 repo**（`.gitignore` 已擋 `_private/`、`members-backup-*.json`）。

## 功能
- 名冊（主畫面）：一戶一列排成樹，家族入信縮在戶長下面；層級自動判斷（沒有導親＝導親、下一層＝導子、再往下＝所屬）
- 苑費：只有戶長那列有格子，點一下切換 空白→v（要繳）→x（不繳）；v 的戶再按「收款」記已收日期。上方自動統計各層級 v 的戶數（＝原 Excel 第 1 列）
- 新增：在某戶按「＋」選「導子」或「家族入信」，關係自動建好
- 匯入／匯出／列印：版型同原 Excel 名冊（多一欄「已收」），匯出的檔可再匯回來。匯入為「全部取代」，匯入前先顯示筆數與要核對的地方（日期打錯、編號可疑、歿者）
- 「我的導親」：只做參考，不列入苑費與統計
- 實踐：一人一列的勾選表（含家族入信），項目：度眾（人數）、奉侍、布施、接心、集會、法會、會座（大乘／歡喜／大歡喜／靈發）、智流學院、其他。有任何一項＝精進中，全空＝未精進；上方統計可點選篩選，可列印
- 個人資料：院生號碼、教師號碼分兩欄；可自訂欄位（預設「靈位」），每人都有，輸入時會提示已填過的值
- 匯出的 Excel 右邊接著實踐與自訂欄位，匯回來時一起還原
- 名冊有卡片（預設，手機好讀：導親、導子幾戶、精進狀態、家族接在下面）和表格兩種看法；祈念證以戶為單位，排在苑費前面
- 匯入名冊改成「對人更新」：信徒編號或姓名對得到的人沿用原本的資料，星供、實踐、奠供帳都保留
- 星供：照星供表排法，一戶一組（戶長、家族入信、跟這戶的未入信者），未入信者也可自成一組；星供、套子、祈念證、苑費、代繳、收款、發送；可匯入／匯出星供表
- 費用：勾選要一起算的人，下方即時合計，可「只算未收」，可複製明細貼到 LINE
- 奠供帳：一戶一本，預存加、申請扣，結餘變負＝代支；可整段貼上 LINE 記事本自動拆成項目與金額；可依月份看當月所有申請並列印
- 金額在「設定」→「年度金額」填，不寫在程式裡
- 生日提醒：生日前 3 天到當天，名冊最上面列出「3 天內生日」，名字旁出現 🎂（名冊、實踐、星供都有）。卡片不顯示出生年月日，只在編輯視窗裡。可在「設定」開這台裝置的通知：沒有推播主機，打開或切回 App 時發，同一人同一次生日只通知一次，內容只有姓名和月／日（iPhone 要先加入主畫面）
- 奠供帳照片：拍照或選照片後先用 canvas 壓成小張 JPEG（長邊 1000px，目標 100KB 內），存在裝置的 IndexedDB；開同步時每張另外存成一份加密私密 Gist（主資料只記照片 id，不拖慢同步）。備份 JSON 不含照片
- 已拿掉：星供、套子、祈年證、代繳、會座、統計頁、關係圖頁

改任何檔案後，`sw.js` 的 `CACHE` 版本號 +1。
