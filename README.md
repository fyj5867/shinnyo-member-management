# 信徒管理

導親・導子・所屬（結緣脈絡）、年度星供申請、苑費・祈年證・星供・套子收費、會座管理。
手機與電腦共用同一份資料（機制同「行動祕書」「安規工具」：加密私密 Gist 同步）。

## 隱私設計
- **這個站台是公開的，程式碼裡沒有任何人名、電話、金額。**
- 資料只存在使用者裝置的 localStorage，與一份 **AES-GCM 加密**的私密 Gist。沒有同步密語就不會上傳。
- 備份 JSON、匯入用的 Excel／PDF／Word 都含個資，**不要放進本 repo**（`.gitignore` 已擋 `_private/`、`members-backup-*.json`）。

## 功能
- 信徒：入信／非入信、電話、生日、地址、會座與職務、導親（引導他結緣的人）；導子＝導親直接引的人；所屬＝導子再引入信者（對導親的統稱，不論幾代）
- 關係圖：由「導親」欄自動長出導子／所屬樹
- 年度：**以「繳費代表」為單位**（預設＝戶長；多戶由一人代繳時，在該人那列按「代繳▾」指定代表，仿原 Excel 星供名單的「組內序 1＝代表」）。每人勾 苑費／祈年證／星供／套子數；「苑費已收（含祈年證）」「星供已收（含套子）」「星供已發送」記在整戶；可篩會座，輸出「星供申請名單」「苑費管理單」（Excel／列印 PDF）；可「帶入去年勾選」
- 統計：依每個人申請的項目算費用（苑費／祈年證／星供／套子），可看依項目、依會座、依個人的應收／已收／未收，並匯出 Excel／列印
- 會座：人數、座長、各座收費概況
- 匯入：Excel／CSV／PDF（文字型）／Word(.docx)／照片。標題列不必在第一列；支援原 Excel 的**區塊格式**（導親／導子／所屬欄＋家族入信欄），並從備註自動抓 S 編號、傳授 I／II／III 日期、歿日；先對欄位預覽再寫入，同名自動合併
